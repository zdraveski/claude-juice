# New forms: eight more battery styles

Picked by KIRE 2026-11-07 from the forms prototype: pie, sand, slider, race, lives, dots, chevrons, ruler.
Confirmed as `battery=` styles (option A), so they show where the styles show: Status bar and Tightest first.

## Shapes (normal width / squeezed width)

| id | shape | width |
|---|---|---|
| pie | one cell `○◔◑◕●` by used, in quarters | 1 / 1 |
| sand | braille grains `⡀⣀⣄⣤⣦⣶⣷⣿`, 8 per cell | 5 / 3 |
| slider | `━` used, `●` knob, `─` rest | 8 / 5 |
| race | `·` track, `●` you, `│` where even use would be now | 9 / 6 |
| lives | `♥` left, `♡` used (counts what is left; any left shows a heart) | 5 / 3 |
| dots | `•` used, `·` rest | 8 / 5 |
| chevrons | `▸` used, `▹` rest | 6 / 4 |
| ruler | `┣` `━` used, `─` rest, `╋` even pace `┫` | 8+2 / 5+2 |

The number sits after the form (a form has no room inside), so Status bar reads `Session ━━━●──── 47%`.

## Decisions

- `FORM_IDS` in `src/schema.js`; `BATTERY_IDS` = the six skins + the forms. The skin tests loop over skins only.
- `form(ctx, pct, level, small, elapsed)` in `src/render/pieces.js`; bar and focus draw it when `ctx.style` is a form.
- No colour: forms differ by shape, so they stay (the six skins still fall back to classic).
- `♥` counts one column in `vis` (it has text presentation by default); before, it counted two, which would
  have made the fit squeeze too early.
- Warnings keep their `!`/`!!` mark, so a warning never rests on colour alone.

## Risk

Fonts: `◔◑◕`, braille and `▸▹` need a font that has them (Cascadia, JetBrains Mono, Menlo do; old Consolas
falls back). README says so next to the styles.
