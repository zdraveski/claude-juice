1Start from a look

One click sets the layout, the colours and what shows. With a mouse, hover over one to preview it first. Then change anything you like below.

2Layout

How the batteries are arranged. Click one to use it; with a mouse, hover to preview it first.

3What to show

Turn off what you don't need, and drag the batteries into the order you like.

4Colours

Green means plenty left, amber means going a bit fast, red means almost empty. Pick a set, or make your own.

Each terminal colour keeps its own picks.

5Details

Small things that change how it reads.

6Use it

Two steps in Claude Code. The status line changes as soon as you press Enter.

1
First time? Install it
/plugin marketplace add zdraveski/claude-juice
/plugin install juice@juice
/reload-plugins
/juice setup

If Claude Code still doesn't know /juice, restart it and type /juice setup again.

2
Apply your settings
Prefer to just say it? Type /juice and ask in your own words, like /juice hide the cost and make it a panel. /juice customize opens this page with your current settings.
