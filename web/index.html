Juice

Make the status line yours

Juice is a status line for Claude Code. It shows how much of your usage limits and chat memory you have left. Pick a look, change what you like, then paste one command into Claude Code.

6Copy it into Claude Code

First time? Run the four install commands once. Needs Node 24 or newer. After that, you only paste your settings command.

1
First time? Install it
/plugin marketplace add zdraveski/claude-juice
/plugin install juice@juice
/reload-plugins
/juice setup

If Claude Code still doesn't know /juice, restart it and type /juice setup again. /juice setup saves a copy of your current status line first, so you can go back.

2
Paste your settings

Paste it into the Claude Code prompt and press Enter. Your status line changes straight away.

Or skip all this: type /juice in Claude Code and say what you want, for example /juice hide the cost and make it a panel. /juice customize opens this page with your current settings.
